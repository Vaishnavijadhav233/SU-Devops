# 03 Epics and User Stories

## Project Epics

| Epic | Purpose | Major Features |
|---|---|---|
| E1 – Student Management | Maintain student information | Registration, profile, search, update, delete |
| E2 – Course Management | Manage courses and assignments | Add, update, assign students, course details |
| E3 – Attendance Management | Maintain attendance | Record, view, attendance reports |
| E4 – Marks & Academic Performance | Manage academic results | Enter/update marks, grades, result sheets |
| E5 – Authentication & Security | Protect access | Login, logout, reset, role-based access |
| E6 – Notifications | Send academic updates | Attendance, exam and result notifications |
| E7 – Reporting | Provide summaries | Student, attendance, performance and course reports |

## User Stories

| ID | Epic | User Story |
|---|---|---|
| US01 | Authentication | As a registered user, I want to log in with my credentials so that I can access the features available to my role. |
| US02 | Authentication | As a user, I want to log out securely so that my account is not left open on a shared device. |
| US03 | Student Management | As an administrator, I want to add a student record so that new students can be maintained in the system. |
| US04 | Student Management | As an administrator, I want to search for a student so that I can quickly find the required record. |
| US05 | Student Management | As an administrator, I want to update student details so that records remain current. |
| US06 | Student Management | As an administrator, I want to delete an incorrect or inactive student record so that the database remains accurate. |
| US07 | Course Management | As an administrator, I want to add a course so that it is available for academic activities. |
| US08 | Course Management | As an administrator, I want to assign students to a course so that course-wise records can be maintained. |
| US09 | Attendance | As a faculty member, I want to record attendance for a selected course and date so that attendance remains accurate. |
| US10 | Attendance | As a faculty member, I want to view attendance reports so that I can identify attendance shortages. |
| US11 | Marks | As a faculty member, I want to enter student marks so that academic performance is recorded. |
| US12 | Marks | As a student, I want to view my result and grades so that I can check my academic performance. |
| US13 | Notifications | As a student, I want to receive important academic notifications so that I do not miss examination or result updates. |
| US14 | Reporting | As an administrator, I want to generate student and academic reports so that management can review the data. |
