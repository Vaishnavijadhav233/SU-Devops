# 07 Agile Frameworks Comparison

## Agile Framework Comparison

| Framework | Main Idea | Suitability |
|---|---|---|
| Scrum | Time-boxed sprints, roles and reviews | High – good for a small student team |
| Kanban | Continuous flow with visual board | Good – useful for continuous task flow |
| XP | Engineering practices, testing and frequent releases | Good – supports code quality |
| Lean Development | Remove waste and focus on value | Good – useful as a supporting approach |
| LeSS | Scales Scrum across teams | Low – unnecessary for this project |
| SAFe | Large-scale coordination | Low – too heavy for a student project |
| Scrum@Scale | Coordinates multiple Scrum teams | Low – unnecessary for one small team |

## Recommended Framework

Scrum is recommended for the Student Record and Academic Management Platform. The project can be divided into short sprints and the team can demonstrate working features after each sprint. Defined Scrum roles make responsibilities clear, while the process gives enough structure without the complexity of large-scale frameworks.

## Conclusion

This Agile plan converts the Student Record and Academic Management Platform requirements into manageable epics, user stories and sprints. Prioritizing the backlog helps the team work on useful features first. Regular Scrum meetings, testing and reviews provide a practical way to track progress and improve the product throughout development.
